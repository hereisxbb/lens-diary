Open Map MVP · v0.3

这版的产品逻辑

先确认「这是哪里」，再把小红书攻略挂上去。地图和 POI 是地点层，小红书是内容层，旅迹只维护两者之间的关系。

开放地图技术栈

地图渲染MapLibre GL JS
全球底图OpenFreeMap / OSM
地点搜索Photon（MVP）
收藏数据TripPins / LocalStorage

以后可以替换的部分

地点搜索层不绑定单一供应商。国内可以接百度 / 高德 POI，海外可以继续使用开放地图数据；TripPins 自己的数据结构不用跟着重做。
