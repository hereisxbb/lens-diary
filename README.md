# Lens Diary

一个面向美瞳用户的个人照片档案和复盘工具，目前是本地 MVP。

当前社区内容均为虚构示例数据，不代表真实用户或真实评价。

## 核心原则

- 不制造消费焦虑
- 用户自己的历史数据优先于平台种草
- 照片和档案默认本地保存
- 社区同时允许种草和避雷
- AI 只帮助理解用户自己的记录，不催促消费

## 当前功能

- 美瞳档案
- 淘宝截图 OCR 参数识别
- 多图照片日记
- 日记封面和原图查看
- 搜索
- 社区
- Lens Agent
- 多主题 UI

## 本地使用

直接打开 `index.html` 即可运行。OCR 功能依赖页面中通过 CDN 加载的 Tesseract.js，因此使用 OCR 时需要联网。

## 给 Codex 的维护说明

- 修改视觉样式优先编辑 `css/style.css`
- 修改交互、数据、本地存储、OCR、日记、社区、Lens Agent 逻辑优先编辑 `js/app.js`
- 修改页面结构和外部资源引用优先编辑 `index.html`
- 保持本地优先，不要默认引入账号体系、后端服务或商城导购逻辑
- 新功能应服务于“记录、复盘、理解自己的佩戴体验”，而不是推动消费
